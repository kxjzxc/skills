# agent-browser

Fast browser automation CLI for AI agents using Chrome or Chromium through CDP, accessibility-tree snapshots, and compact element references.

## Workflow

Before using browser automation, load the core workflow from the installed agent-browser CLI so that the instructions match the installed version.

The core workflow covers navigation, page inspection, interaction, data extraction, screenshots, authentication, sessions, and troubleshooting.

## Specialized workflows

agent-browser also provides specialized workflows for Electron desktop applications, Slack automation, exploratory testing and QA, API-client derivation, Vercel Sandbox, protected Vercel deployments, and AWS Bedrock AgentCore cloud browsers.

Use the installed CLI's skill listing to discover the currently available specialized workflows.

## Why agent-browser

- Fast native Rust CLI
- Chrome/Chromium via CDP
- Accessibility-tree snapshots with compact element references
- Session and authentication state persistence
- Browser automation for web and supported desktop applications
- Works with Codex, Claude Code, Cursor, Windsurf, and other AI agents
