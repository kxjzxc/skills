---
name: code-review
description: Review changes against repository standards and the originating spec.
---

Review the diff between `HEAD` and a fixed point supplied by the user. Identify the spec source and repository coding standards. Review on two independent axes: Standards and Spec. Standards checks documented conventions plus relevant code smells; Spec checks missing or partial requirements, scope creep, and incorrect implementations. Report the two axes separately and do not let one mask the other.
