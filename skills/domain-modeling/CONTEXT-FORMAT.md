# CONTEXT.md Format

```md
# {Context Name}

{One or two sentence description.}

## Language

**Term**:
A tight definition of what it IS.
_Avoid_: Other names for the same concept
```

Rules: be opinionated, keep definitions tight, include only terms specific to the project context, and group terms when useful. A single-context repo uses a root `CONTEXT.md`; multi-context repos may use `CONTEXT-MAP.md`.
