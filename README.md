# My Skills

A personal collection of AI agent skills I want to use, study, and maintain.

## Skills

- [grill-me](skills/grill-me/SKILL.md) — Relentless interviewing for stress-testing plans and designs.

## Install

Install a skill directly from this repository:

```bash
npx skills add https://github.com/kxjzxc/skills --skill grill-me
```

## Principles

- Keep each skill independently installable.
- Follow the standard `skills/<skill-name>/SKILL.md` structure.
- Record the original source when a skill is based on a third-party skill.
- Prefer maintaining the actual skill definition here rather than keeping a separate reference-only copy.
