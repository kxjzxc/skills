# grill-me

## Source

- Author: Matt Pocock
- Repository: `mattpocock/skills`
- Skill: `grill-me`
- Purpose: Relentless interviewing to stress-test plans and designs through systematic questioning.

## What it does

`grill-me` turns a plan, design, or architecture proposal into an interactive review session. It asks questions branch by branch, digs into assumptions and edge cases, and can inspect the codebase when relevant.

Typical uses:

- Design reviews
- Architecture validation
- Pre-implementation planning
- Finding missing requirements and hidden assumptions

## Installation

```bash
npx skills add https://github.com/mattpocock/skills --skill grill-me
```

## Notes

The skill is useful as a pre-implementation gate: first make the design explicit, then use `grill-me` to challenge it before implementation begins.

For this repository, keep the entry focused on how and why the skill is used rather than copying the upstream implementation.
